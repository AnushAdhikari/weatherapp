# WeatherApp

A simple and modern weather application built with React and Vite.

The app lets users search for current weather information for cities around the world. Users can also use their current location and switch between Celsius and Fahrenheit.

## Features

- Search weather by city name
- Use current location to get weather
- View current temperature and weather condition
- Switch between Celsius and Fahrenheit
- View humidity, wind speed, pressure, visibility, sunrise, and sunset
- Responsive design for mobile and desktop
- Loading and error messages

## Technologies Used

- React
- Vite
- JavaScript
- CSS
- OpenWeatherMap API
- Vercel

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/AnushAdhikari/weatherapp.git
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Create a `.env` file in the project root and add your API key:

   ```env
   VITE_WEATHER_APP_ID=your_openweathermap_api_key
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```
